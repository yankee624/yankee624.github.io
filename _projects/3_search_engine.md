## Document Search Engine

A course project for *Information Modeling Methods and Their Applications* at Seoul National University, Spring 2019.

### Project Overview

Developed an enhanced document search engine by implementing traditional search engine optimization techniques and integrating modern web search capabilities.

### Technical Implementation

- **Traditional Search Engine Optimization**: Implemented classical information retrieval techniques including indexing, ranking, and query processing
- **Query Parser Enhancement**: Improved the query parsing system by integrating Google Search API to leverage state-of-the-art search capabilities
- **Hybrid Approach**: Combined traditional IR methods with modern web search to achieve better search quality

### Skills Developed

- Information retrieval algorithms
- Search engine architecture
- API integration
- Query processing and optimization
